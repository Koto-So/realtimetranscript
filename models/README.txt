====================================================
  LLM モデルの配置場所
====================================================

このフォルダに以下の GGUF ファイルを配置してください:

  Qwen3.5-0.8B-Q4_K_M.gguf

ダウンロード手順:
  setup.ps1 を実行すると自動でダウンロードされます。

  手動ダウンロードの場合:
  https://huggingface.co/Qwen/Qwen3-0.8B-GGUF
  上記ページから Qwen3.5-0.8B-Q4_K_M.gguf をダウンロードして
  このフォルダに配置してください。

配置後のフォルダ構成:
  models/
    Qwen3.5-0.8B-Q4_K_M.gguf  ← これを配置（約 500MB）

注意:
  モデルファイルは大容量のため .gitignore で除外されています。
  GitHub へはアップロードされません。
